# customer-faq · 客服 FAQ 与话术

> 让客服回复"专家级回答 + 标准化语气"，不再依赖个人经验。

---

## When to Activate

- 用户说"代理问 xx 怎么回答"、"客户咨询 xx"
- 客服接到工单
- 客服需要查询业务规则解释

---

## 答复结构（4 段式）

```
1. 共情（Empathy）       理解对方的处境
2. 答复（Answer）        清晰准确回答
3. 行动（Action）        告诉对方下一步该怎么做
4. 升级（Escalation）    如果复杂超出范围，给升级路径
```

## 高频 FAQ 分类

### A · 佣金相关

#### Q1：为什么我没收到这个月的佣金？

```
[共情] 您好 {name}，关于本月佣金的疑问，已为您查询。

[答复] 根据系统记录：
  - 您本月已生成佣金 X 笔，金额 $Y
  - 当前结算单状态：{status}
  - 预计到账时间：{date}

如未收到，可能因为以下原因之一：
  1. 协议尚未签署（请到"我的协议"页查看）
  2. 客户未达到 QFTD 合格条件
  3. 出金审批中

[行动] 请您：
  1. 在 client 端"我的佣金"页查看明细
  2. 如需进一步核实，请回复工单并提供 cpaAccount

[升级] 涉及金额对账请 @ 财务团队（按客服流程升级）
```

#### Q2：FTD 是什么？

```
[共情] 您好，这是一个常见疑问，为您解释下：

[答复] FTD = Qualified First Time Deposit，即"合格首次入金"。
客户的首次入金满足以下条件才算合格：
  - 金额达到阈值
  - 在规则规定的时间窗内
  - （可能）满足交易量要求

具体条件见您签署的协议附件。

[行动] 您可以在 client 端"协议详情"中查看您的 QFTD 标准。

[升级] 如对协议条款有疑问 → @ 业务运营
```

### B · 出金相关

#### Q3：我的出金为什么一直审核中？

```
[共情] 您好，出金审核通常需要 1-3 个工作日，您耐心稍候。

[答复] 您的出金申请单号：{payNo}
  - 提交时间：{submitTime}
  - 当前状态：审核中（P）
  - 当前节点：{currentNode}
  - 等待审批人：{approver}

[行动] 通常审核会在 24-48 小时内完成。如超过 48 小时无进展：
  1. 联系您的对接销售
  2. 或回复本工单要求加急

[升级] 大额出金（>$10,000）走人工复核 → @ 财务团队
```

#### Q4：我的出金被拒了为什么？

```
[共情] 您好，关于出金被拒的疑问，已为您查询。

[答复] 您的申请 {payNo} 被拒，原因：{reason}
  - 可能原因 1：可用余额不足（含锁定）
  - 可能原因 2：超出单笔限额
  - 可能原因 3：风控规则触发（需补充资料）
  - 可能原因 4：账户状态异常

[行动] 请您：
  1. 查看"我的余额"页，确认可用 / 锁定金额
  2. 如确认无误，请重新提交（金额≤可用余额）
  3. 风控相关请补充资料

[升级] 风控冻结 → @ 风控团队
```

### C · 协议相关

#### Q5：协议条款变了怎么办？

```
[共情] 您好，规则变更需要您重新签署，这是为了保护您的利益。

[答复] 根据本次规则变更，您需要重新签署协议：
  - 旧协议失效时间：{date}
  - 新协议条款摘要：{summary}
  - 您的已生成佣金不受影响（按旧快照计算）

[行动] 请在 7 天内到 client 端"我的协议"页完成签署。

[升级] 对新协议有异议 → @ 业务运营商讨
```

### D · 关系 / 客户相关

#### Q6：为什么我的客户被转到别的代理了？

```
[共情] 您好，关于客户关系变更，已为您查询。

[答复] 您的客户 {clientId} 在 {date} 被转移到代理 {newAgent}。
转移可能由以下原因之一触发：
  1. 客户主动申请变更
  2. 运营基于规则的批量调整
  3. 风控决定

[行动] 如对转移有异议：
  1. 提供具体证据
  2. 回复工单升级

[升级] 重大争议 → @ 业务负责人
```

### E · 技术故障

#### Q7：登录不了 / 接口报错

```
[共情] 您好，遇到技术问题，已为您查询。

[答复] 可能原因：
  1. 密码错误（请用"忘记密码"重置）
  2. 账号被锁定（连续失败 5 次会锁 30 分钟）
  3. 服务暂时不可用（看 https://status.cpa.com）

[行动] 请尝试：
  1. 清除浏览器缓存重试
  2. 用无痕模式
  3. 截图错误信息

[升级] 持续故障 → @ 运维（参考 oncall-trading）
```

## 客服语气规范

### 必做

- ✅ 称呼客户（"您"，不要"你"）
- ✅ 先共情再解决
- ✅ 给出具体数据 / 时间 / 路径
- ✅ 必要时主动升级

### 不做

- ❌ 套话敷衍（"亲请稍等"）
- ❌ 推卸（"不归我管"）
- ❌ 承诺不能兑现的（"24 小时一定解决"）
- ❌ 泄露其他客户信息
