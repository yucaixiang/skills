# 交易系统值班手册

## 常见告警处理

### 撮合延迟告警
**现象**: 撮合延迟 > 100ms
**排查步骤**:
1. 检查撮合引擎 CPU 和 GC 情况
2. 检查订单队列积压量
3. 查看是否有异常大单

**处理**:
- 轻微: 观察，等待自动恢复
- 严重: 触发限流，通知交易运营

### 订单簿不一致
**现象**: 买卖盘数据不匹配
**排查步骤**:
1. 对比撮合引擎内存状态与 Redis 快照
2. 检查最近的快照时间
3. 查看是否有未确认的成交

**处理**:
- 触发全量快照重建
- 如严重：暂停交易对，重建订单簿

### 资金异常
**现象**: 用户余额与流水不一致
**排查步骤**:
1. 核对充值/提现流水
2. 检查成交扣款记录
3. 对比结算系统数据

**处理**:
- 冻结相关账户
- 通知风控和运营
- 人工核实后解冻
