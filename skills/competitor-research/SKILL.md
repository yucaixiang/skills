# competitor-research · 竞品分析框架

> 让竞品分析从"凭印象写"升级为"结构化拆解"。

---

## When to Activate

- 用户说"分析一下 xx 产品"、"对标 xx"
- 用户说"我们要做 xx 功能，看看竞品怎么做的"
- 立项前的市场调研
- 评估某个功能要不要做

---

## 竞品拆解 7 维度框架

```
1. 产品定位       一句话总结：他们是做什么的，给谁用
2. 功能矩阵       核心功能清单 + 我们对比
3. 定价模式       怎么收费、价格档位
4. 用户评价       好评 / 差评 / 真实痛点
5. 技术栈         能查到的技术信息
6. 市场份额       客户数 / 收入 / 增长
7. 差异化机会     我们能赢在哪 / 学在哪 / 避开哪
```

---

## 维度 1 · 产品定位

### 问题清单

- 一句话定位是什么？（slogan）
- 解决的痛点是什么？
- 目标用户是谁？（个人 / 企业 / 行业）
- 处于哪个生命周期？（探索期 / 增长期 / 成熟期 / 衰退期）

### 调研方法

- 官网首页（slogan + 解决方案描述）
- About / Company 页
- 投资资料 / 新闻稿
- 创始人公开访谈

### 输出模板

```
【竞品名】：xxx
【一句话定位】：xxx
【核心痛点】：xxx
【目标用户】：xxx
【生命周期】：xxx 期，主要标志是 xxx
```

## 维度 3 · 定价模式

### 维度

| 维度 | 选项 |
|---|---|
| 收费模式 | 按月 / 按年 / 按交易量 / 按客户数 / 一次性 / 免费+增值 |
| 试用 | 有 / 无 / 多长 |
| 档位数 | 通常 3-4 档 |
| 透明度 | 明码标价 / Contact us |

### 输出模板

| 档位 | 价格 | 限额 | 关键功能 |
|---|---|---|---|
| Starter | $99/mo | 100 客户 | 基础 CPA |
| Pro | $499/mo | 1000 客户 | + 自动化 + API |
| Enterprise | Contact us | 无限 | + 定制 + SLA |

**洞察**：
- 定价反推目标客户：Pro 价 $499 → 中小代理团队
- 限额揭示用户规模分布

## 维度 6 · 市场份额

### 关键数据

- 客户数（公开宣称）
- 收入 / ARR（如有融资公开）
- 增长率
- 主要市场（地区 / 行业）
- 大客户名单

### 数据源

- Crunchbase
- LinkedIn 员工数（间接反映规模）
- 财报（如上市）
- 第三方报告（Gartner / Forrester）

---

## 维度 7 · 差异化机会

### 三个核心问题

#### 问题 1 · 我们能"赢"在哪？

- 找竞品 ❌ 而我们 ✅ 的功能
- 找竞品 ⚠️ 但我们 ✅ 强的功能
- 找用户负面评价中的痛点

#### 问题 2 · 我们可以"学"什么？

- 竞品 ✅ 但我们 ❌ 的功能
- 哪些是必备项（行业标配）→ 必须补齐
- 哪些是创新点（值得抄）→ 评估抄不抄

#### 问题 3 · 我们应该"避"什么？

- 竞品已占据的差异化方向（如"全球化多语言"）
- 红海赛道（如"价格战"）
- 成本不可控的方向（如"开放无限制免费版"）

## 实操技巧

### 技巧 1 · 用 lark-cli 把报告同步到飞书

```bash
lark-cli docs +create --api-version v2 \
  --content '<title>2026Q2 竞品分析</title>...' \
  --space '/产品组/竞品研究'
```

### 技巧 2 · 用 lark-cli 自动 @ 相关人

```bash
lark-cli im send --chat '#产品组' \
  --content "新竞品报告已上传：[链接]，@张三 @李四 请 review"
```

### 技巧 3 · 季度回顾

每季度复用本 Skill 跑一遍，对比上季度变化：
- 竞品新增了哪些功能？
- 价格变了吗？
- 评价变了吗？

## 常见误区

| 误区 | 改正 |
|---|---|
| 只看官网功能列表 | 必须试用 + 看真实评价 |
| 只对比功能数量 | 重点是"功能深度" + "用户体验" |
| 忽略价格档位 | 价格揭示目标客户 |
| 看不到的不写 | 主动调研，看不到也要标"未知"而不是回避 |
| 抄完竞品就赢了 | 抄是补齐，赢靠差异化 |
