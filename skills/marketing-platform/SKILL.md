# 营销平台

## 概述
营销活动管理平台，支持优惠券、拉新活动、裂变分享、积分兑换等营销工具。

## 核心功能
- 优惠券系统 — 创建/发放/核销/过期
- 活动引擎 — 可视化配置营销活动
- 邀请体系 — 多级邀请关系追踪
- 数据看板 — 实时活动效果分析

## 技术架构
- 后端: Spring Boot + MyBatis-Plus
- 缓存: Redis Cluster (优惠券库存)
- 队列: RocketMQ (异步发券)
- 定时任务: XXL-JOB

## 注意事项
- 优惠券发放需校验库存，使用 Redis Lua 脚本保证原子性
- 邀请关系深度限制 10 级
- 活动开始/结束时间使用定时任务触发状态变更
